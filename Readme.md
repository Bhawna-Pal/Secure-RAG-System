🔐 Secure RAG System with Guardrails

A Secure Retrieval-Augmented Generation (RAG) System that allows users to ask questions about private or custom documents while applying security guardrails to control what information can be retrieved and generated.

The project combines RAG, document retrieval, backend APIs, and AI guardrails to create a safer AI-powered question-answering system.

🚀 Features
📄 Upload and process documents
🔎 Semantic document search
🤖 AI-powered question answering
🧠 Retrieval-Augmented Generation (RAG)
🔐 Security guardrails
🛡️ Prevent unsafe or restricted queries
🔒 Control access to sensitive information
📚 Context-aware responses
🌐 REST API based backend
💬 User-friendly chat interface
⚡ Fast document retrieval
